# 钱迹 · 个人财务看板

可在手机或电脑浏览器使用的个人账本。支持手动记账、批量截图识别、分类、周月年报、预算和资产记录。

## 开始使用

首次打开是空白个人账本。可以在「账本设置」切换到虚构示例，或直接在「流水」记一笔、在「总览」导入账单截图。

账本保存在当前设备的浏览器中，每位使用者独立记账。截图由浏览器本地识别。账本不会跨设备同步；清理站点数据可能删除账本。可导出 JSON 留存，目前完整账本尚不能直接导回。

## 本地预览

在项目目录运行：

```sh
python3 -m http.server 8080
```

打开 <http://localhost:8080/>。截图识别依赖浏览器安全上下文，使用 HTTPS 或 localhost。

## 部署到 GitHub Pages

将项目根目录内的文件上传到仓库。打开 **Settings → Pages**，选择 **Deploy from a branch**，然后选择 **main / (root)**。发布成功后，Pages 页面会显示可分享的使用地址。

OCR 使用 Tesseract.js。组件许可文件保留在 `ocr/` 目录。
